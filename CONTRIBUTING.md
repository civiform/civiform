# Contributing to CiviForm

**We aren't accepting code contributions from outside the CiviForm team right now.** That covers pull requests and requests to be assigned an issue. The team is engineers from Exygy, Google, and civic entities working on CiviForm. This may change down the road.

Team members: see the [Technical contribution guide](https://github.com/civiform/civiform/wiki/Technical-contribution-guide).
